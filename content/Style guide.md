| ------ | ---------------------------------- | -------------------------------- | ------------ | --------- |

| Orange | <code class="orange">Orange</code> | `#DB8942`                        | `#DDC19C`    | `#614428` |

| Gray   | <code class="gray">Gray</code>     | `#5A6978` light / `#A0A0A0` dark | `#B6B7AD`    | `#3F4241` |

| Role            | Used for                 | Light mode                 | Dark mode                  |
| --------------- | ------------------------ | -------------------------- | -------------------------- |
| `light`         | Page background          | `#DED9C3`                  | `#161A18`                  |
| `lightgray`     | Borders, code background | `#C9C4AD`                  | `#2F3532`                  |
| `gray`          | Muted text, icons        | `#8A8672`                  | `#6C7570`                  |
| `darkgray`      | Body text                | `#45423A`                  | `#CFCAB5`                  |
| `dark`          | Headings, strong text    | `#26241F`                  | `#DED9C3`                  |
| `secondary`     | Links                    | `#23634F`                  | `#5FB89B`                  |
| `tertiary`      | Hover, accents           | `#349176`                  | `#349176`                  |
| `highlight`     | Link and selection tint  | `rgba(52, 145, 118, 0.15)` | `rgba(52, 145, 118, 0.15)` |
| `textHighlight` | Marker-style highlight   | `#fff23688`                | `#b3aa0288`                |
